## 访问链路

```text
Browser
  → 43.163.92.244:443 / ai_video_nginx
  → lighthouse_ai_video_net
  → data_achieve_scrapy_proxy:8080 / data_achieve_scrapy_edge
  → Console 或 API
```

共享 `ai_video_nginx` 在 80/443 终止 TLS。`scrapy.luteos.com` 的 Nginx upstream 为 `data_achieve_scrapy`，该 upstream 指向 `data_achieve_scrapy_proxy:8080`。当前链路不经过旧内网服务器或 SSH 反向隧道。

## 最小验收

```bash
curl -fsSL https://scrapy.luteos.com/api/health
curl -fsSL https://scrapy.luteos.com/api/platform-packages
curl -fsSI https://scrapy.luteos.com/platforms
curl -sS -L -o /dev/null -w '%{http_code}\n' https://scrapy.luteos.com/mcp
```

预期结果：

- health 返回 `status=ok`、`database=connected`、`schema=current`。
- 平台包返回 `70 / 270 / 242`。
- `/platforms` 返回 `200`。
- 未携带 Token 的 `/mcp/` 返回 `401`。
