## 6. 术语

| 术语 | 含义 |
|---|---|
| 能力视图 | 工具在某平台分类下的展示条目。同一端点可出现在多个视图 |
| 唯一端点 | 按 `endpoint_type` 去重后的可调用入口 |
| verified | 最新一次 test 运行成功，且返回至少 1 条记录 |
| config-gated | 端点可用，但需要凭据、自建服务或受控出口 |
| degraded | 最近一次实测失败，问题在上游 |
| empty | 实测成功，但返回 0 条 |
| untested | 未执行 test 运行。不等于失败 |
| executable | 工具目录中当前可调用的工具。不等于 verified |
| MCP | Model Context Protocol。本项目入口在 `/mcp/` |
| ABI | 外部数据中心。应用侧为 PG16；外部仓为 PG18.6 本地快照 |
| dataset | ABI 中的一张数据表，带版本与 PII 策略 |
