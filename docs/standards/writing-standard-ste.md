# 技术写作标准（ASD-STE100 等效）

## 1. 目的

本文件规定本项目的中文技术写作规则。

规则来自 ASD-STE100 Issue 9。该标准用于英文技术文档。中文没有官方 STE 版本。本项目采用它的等效规则。

## 2. 适用范围

1. AI 的每轮结果回复。
2. 所有 README.md 文件。
3. `docs/` 目录下的文档。

## 3. 核心规则

| 编号 | 规则 | 说明 |
|---|---|---|
| R1 | 一名一义 | 一个术语只表示一个概念。不要用同义词替换术语。 |
| R2 | 一句一个意思 | 一句话只说一件事。 |
| R3 | 句子要短 | 步骤句不超过 20 字。描述句不超过 25 字。 |
| R4 | 用主动语态 | 只有执行者未知时，才用被动语态。 |
| R5 | 只用简单时态 | 用现在时和过去时。 |
| R6 | 不用复合时态 | 不要用「已经完成」「正在进行」这类结构。 |
| R7 | 多步骤用列表 | 一个编号一个动作。 |
| R8 | 不用修辞 | 不用成语、比喻、口语、缩略语。 |
| R9 | 先结论后原因 | 第一句给结论。 |
| R10 | 名词短语要短 | 不超过 3 个词。 |
| R11 | 要求用「必须」 | 建议用「建议」。不要用「应该」。 |
| R12 | 不用连接词堆叠 | 一句话不要串多个「并且」「以及」。 |

## 4. 中文适配

英文 STE 的这 3 条规则不适用于中文：

1. 冠词规则。中文没有冠词。
2. 复数规则。中文没有单复数变化。
3. 词性规则。中文没有严格的词性标注。

中文用「字」作为长度单位。

技术名词可以保留英文。例如 endpoint、dataset、collector。

## 5. 术语表

写文档时，只用左列的术语。

| 术语 | 含义 | 不要用 |
|---|---|---|
| 采集 | 运行收集器获取数据 | 抓取、爬取、拉取 |
| 数据集 | Dataset | 数据资产、数据集合 |
| 端点 | endpoint | 接口、采集点 |
| 平台包 | platform package（Skill） | 工具包、能力包 |
| 坑点 | 已知问题与规避方法 | 陷阱、雷区 |
| 抽屉 | 右侧滑出面板 | 弹窗、侧边栏 |
| 版本 | DatasetVersion | 快照、批次 |

## 6. 复检清单

写完一段，就查这 6 项：

1. 每句话是否只有一个意思？
2. 是否用了主动语态？
3. 是否用同义词替换了术语？
4. 步骤句是否超过 20 字？
5. 是否用了成语或口语？
6. 名词短语是否超过 3 个词？

## 7. 例外

以下情况可以违反规则：

1. 代码、命令、路径、字段名。这些内容必须保持原样。
2. 引用他人的原文。
3. 专有名词的官方译名。
