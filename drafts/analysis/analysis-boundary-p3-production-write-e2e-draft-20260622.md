# P3 Production Write E2E Execution

## 0. Boundary

User authorization: "同意执行 P3".

Interpreted scope:

- Run a scoped L4 production write E2E against `https://scrapy.lute-tlz-dddd.top`.
- Use one-time `e2e-*@example.com` users/workspaces only.
- Execute fixture cleanup dry-run, cleanup execute, and recount immediately after the E2E.
- Recheck production health, public pages, SHA, and compose status.

Not executed:

- No full real Playwright suite.
- No report send or report subscription execution.
- No external email send.

- No demo seed.
