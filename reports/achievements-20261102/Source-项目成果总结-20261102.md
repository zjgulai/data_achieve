- 六档证据按 first match wins 判定：Not authorized > Blocked > Evidence gap > Confirmed > Directional > Supported hypothesis。Directional 要求同一 frame 内至少 8 条独立记录、至少 2 位作者、方向一致度至少 70%。
- 六级计数链：raw_object → occurrence → canonical_record → frame_membership → annotation → metric_row。本轮实测 raw 430、occurrence 430、canonical 423、membership 432。membership 大于 occurrence，因为同一条记录可进入多个 frame；它不是漏斗。
- 视频层有 141 条视频、124 位达人、10 条 exact 基线。没有任何层同时满足层内 n≥8 与对照 n≥8。字幕、音轨、画面为 Evidence gap。
- metric rows 为 0，G7 为 BLOCKED。原因是缺第二编码员与逐字段 agreement。量化结论不可用。
- run-20261029 的报告校验 34 项、spec 校验 13 项、单测 139 个 `test_` 方法。以上是资产与历史运行记录，当日未复跑。

## 6. 术语

| 术语 | 含义 |
|---|---|
| 能力视图 | 工具在某平台分类下的展示条目。同一端点可出现在多个视图 |
| 唯一端点 | 按 `endpoint_type` 去重后的可调用入口 |
| verified | 最近一次 test 运行成功，且返回 ≥1 条记录 |
| config-gated | 端点可用，但需要凭据、自建服务或受控出口 |
| degraded | 最近一次实测失败，问题在上游 |
| empty | 实测成功，但返回 0 条 |
| untested | 未执行 test 运行。不等于失败 |
| executable | 工具目录中当前可调用的工具。不等于 verified |
| MCP | Model Context Protocol。本项目入口在 `/mcp/` |
| ABI | 外部数据中心。应用侧为 PG16；外部仓为 PG18.6 本地快照 |
| dataset | ABI 中的一张数据表，带版本与 PII 策略 |
| T-1 | 目标日为前一天的扫描任务 |
| actor | Apify 数据的来源 Actor，用于归因 |
| VOC | Voice of Customer，用户声音洞察 |
| 六档证据 | Not authorized / Blocked / Evidence gap / Confirmed / Directional / Supported hypothesis |
| 禁写闸门 | 报告渲染前的机器检查。命中禁止结论即失败 |
| G7 | VOC 的第二编码员与一致性校准门 |
| ADR | Architecture Decision Record，架构决策记录 |
| STE | ASD-STE100 简化技术英语。本项目使用等效中文规则 |
