## 1. 结论

Monid 的核心价值在于路径短，不在于外观复杂。

它把「找到工具 → 看清参数 → 交给 Agent 使用」压成一条直线。
本项目的目标是借鉴这条路径，不移植它的运行时。

已确认的产品方向见 [整站能力整合方案](./【技术方案】DIH整站能力整合方案.md)。

- 区块垂直内边距：100px 或 140px。
- 圆角：3、4、6、8、16、50、999px。
- 按钮圆角 8px。
- 卡片圆角 16px。
- 状态标签使用胶囊形 999px。
- 内容最大宽度：1240px 或 1100px。

### 5.4 颜色

- 主强调色：`#0016d7`。
- 标题色：`rgb(30, 30, 30)`。
- 次要文字：`rgb(107, 107, 107)`。
- 页面底色：白色。
- 行动区块底色：主强调色满铺。
- 终端区块底色：近黑。

### 5.5 视觉手法

- 首屏用大字号标题加两行彩色强调词。
- 首屏背景是低对比度二进制纹理，不干扰正文。
- 一条黑色命令行加复制按钮，形成唯一主行动。
- 工具墙用真实品牌图标，密度高但排布整齐。
- 行动区块用满色背景制造节奏断点。
- 截图与数字区块交错，避免连续长文。
- 全站几乎不用阴影，层次靠边框与底色区分。

### 5.6 值得借鉴的做法

1. 首屏只讲一件事，只给一个动作。
2. 用真实客户或工具图标建立可信度。
3. 用大小对比制造节奏，不用装饰动画。
4. 技术细节放折叠区或详情页。
5. 深色区块作为节奏断点，不滥用。
6. 文案短句为主，一句一个意思。

### 5.7 不宜照搬的部分

1. 蓝色主色与 Monid 标志。
2. 二进制纹理与像素吉祥物。
3. 钱包、订阅与计费文案。
4. 未经本项目验证的工具数量与价格。
5. 外部字体依赖（Outfit 等）。

本项目品牌映射见 [首页与目录视觉规范](./【设计规范】DIH首页与目录视觉规范.md)。

## 6. 源码能力边界

固定源码：`monid-ai/monid@74d772d64738f71120b50615390455d78a24e3c5`。

公开仓库明确定位为连接器层，不是完整网站、账户系统或支付服务。

| 能力 | 级别 | 边界 |
|---|---|---|
| Provider / Endpoint / Resource 契约 | S | 提供商、输入、结果、价格与限制声明 |
| Bundle 目录读取 | S | list / inspect 纯函数 |
| 本地端点执行 | S | Deno / TypeScript，含开始、轮询、停止与用量计算 |
| 托管 discover 排序 | D / U | 文档可见，仓库无完整平台实现 |
| 产品 MCP / Skill / CLI | D / U | 不得与仓库开发 CLI 混同 |
| 统一钱包与账单 | D / U | 价格字段不是扣款账本 |
| 网站 UI 与登录后控制台 | U | 仓库无完整前端页面 |

MIT 许可不得解释为商标或整站素材授权。
本项目保留自有名称、图标、文案与视觉。

## 7. Designeer 的适用部分

`/designers` 是目录，不是可直接安装的组件库。

可借鉴：

- 左侧分类与明确选中态。
- 紧凑行高、图标、名称与一句说明。
- 搜索弹窗与明确无结果状态。
- 列表与网格切换控件。
- 图标按钮的可访问名称。

不直接采用：

- 广告轮播与浮动广告。
- 设计师头像、品牌图与外链作品。
- 装饰性栅纹与像素球。
- 未经本项目可访问性验证的动效与弹窗行为。
