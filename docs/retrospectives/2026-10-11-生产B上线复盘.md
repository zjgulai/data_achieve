## 诊断记录

api 镜像构建停滞。以下是根因链。

1. 现象：uv 下载阶段宿主流量只有约 50 KB/s。
2. 排除 uv：直接测速，26 MB 包 4 秒装完。
3. 排除镜像源本身：小文件测速为 429-495 KB/s。
4. 对比实验：设 `UV_DEFAULT_INDEX` 与 `UV_INDEX_URL` 后，请求仍全部发往 `files.pythonhosted.org`。
5. 根因：`uv sync --frozen` 只按锁文件里的绝对地址下载。索引变量不生效。
6. 修法：构建时改写锁文件主机名。路径与 sha256 不变。
7. 验证：镜像源返回 200，sha256 与锁文件一致。
8. 结果：api 镜像主步骤 337 秒构建完成。

## 坑点表

| 坑点 | 现象 | 规避 |
|---|---|---|
| 宿主 DNS 与容器 DNS 不同 | `mirrors.tencentyun.com` 容器内 ENOTFOUND | 换源前在容器内验证 |
| 锁文件带绝对地址 | 换索引变量无效 | 构建时改写锁文件 |
| corepack 尾斜杠 | `//pnpm/...` 返回 404 | registry 不带尾斜杠 |
| 管道吞退出码 | 重试循环一次失败就 break | 用变量接输出，保留 `$?` |
| pkill 自匹配 | 杀掉执行中的 SSH 会话 | 模式写成 `[c]ompose` |
| 对比两侧格式不一致 | 隔离核对出现假阳性 | 先对齐格式再 diff |
| 源码硬编码域名 | 前端串台 | 复核产物里的域名集合 |
| `reset --hard` 被拦 | 同步中断 | 用 `merge --ff-only` |
| Playwright CFT 路径 | 下载 400 | 按版本核对路径 |
| ENV 覆盖同名 ARG | 构建参数不生效 | ENV 写 `${ARG_NAME}` |

## 复盘

### 做对的事

1. 诊断用证据链。每步排除一个假设，不猜测。
2. 修复后立即验证。哈希与测速都留证据。
3. 隔离纪律严格。全程只 `nginx -s reload`。非 DIH 容器零差异。
4. 修复走源码路径。不在生产机上热改文件。
5. 发现串台后先定性。区分展示字符串与 API 基址，再决定修法。

### 做错的事

1. 重试循环两次因 `| tail` 吞掉退出码。一次旧构建白跑。
2. `pkill -f` 模式自匹配，杀掉自己的会话。
3. 首次选镜像源只看宿主机解析。没有先在容器内验证。
4. Playwright 下载地址凭记忆构造。收到 400 才实测。
5. 隔离对比时两侧格式不同。输出一篇假阳性。
6. 生产 A 用 `reset --hard`。被权限分类器拦下。改用 `--ff-only` 反而更安全。

### 防呆措施

1. 重试循环统一写法：`out=$(cmd 2>&1); rc=$?`。
2. 换源必须先跑容器内解析与测速。
3. 外部下载地址必须先验证再进 Dockerfile。
4. 对比类命令先对齐两侧格式。
5. 生产同步统一用 `fetch` + `merge --ff-only`。
6. 以上写入技能，见 `.claude/skills/production/`。
