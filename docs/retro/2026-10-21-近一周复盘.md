## 4. 经验转环境资产机制

原则：每条经验必须落到一个可执行资产，不能只留在对话里。

| 机制 | 资产 | 触发时机 | 验收 |
|---|---|---|---|
| 生产前置检查 | `scripts/preflight-production.sh` | 每次部署前后 | 全部 PASS |
| 部署边界 | 生产重启只执行 `up -d api console` | 每次发布 | edge 固定 IP 172.20.0.16 仍在 |
| 上游样本 | 新端点先取原始响应，落测试 fixture | 接入新 provider/actor | 归一化测试使用真实字段 |
| 契约测试 | 工具数量、端点映射从注册表派生 | 新增工具/端点 | 不写死数量 |
| 回填保护 | 逐条 savepoint + 只更新不覆盖新数据 + 冲突计数 | 每次回填 | `failed_records=0`，冲突可解释 |
| 密钥检查 | Fernet 长度 44 与加解密往返 | 部署前 / 轮换后 | `VAULT_KEY_LEN 44` |
| 记忆条目 | `.claude/.../memory/*.md` | 事故修复后 24 小时内 | MEMORY.md 有一行索引 |
| 复盘节奏 | `docs/retro/YYYY-MM-DD-*.md` | 每周五或重大事故后 | 事件、根因、资产、ticket 四段齐全 |
