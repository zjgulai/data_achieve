## 6. 方法论沉淀(哪些做法值得复制)

1. **「七代理差距分析 → 对抗验证 → 人工拍板 → 逐日执行 → 证据归档」**
   的冲刺骨架:45 个 blocker 在计划期消化,执行期只遇到 1 个未预判问题
   (sweep project_id)。代价是计划期花了半天——值。
2. **证据目录先行**:验收落点(EVID/01~09)在计划里就定好,执行时
   边做边写,收口零补工。
3. **「我准备、人执行」的对外操作模式**:PMO 回写、ADR 签字全部出
   清单+文案,用户一键执行——既守住登录态边界,又不阻塞进度。
4. **每个坑当场进 nmem**:26+ 提交跨 5 个会话接续执行,记忆是唯一的
   跨会话上下文;复盘的 P 级坑全部能在 nmem 找到第一次记录。
