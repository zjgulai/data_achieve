# DIH 首页与工具目录视觉规范

> 参考对象：`https://monid.ai`（首页与目录）· `https://www.designeer.xyz/designers`（目录组件）
> 依据：[Monid 逆向报告](./【逆向报告】Monid网站UI与能力逆向.md)
> 品牌来源：[产品设计规范](../../opendesign/design-systems/data-intelligence-product/DESIGN.md)
> 相邻文档：[整站能力整合方案](./【技术方案】DIH整站能力整合方案.md)

## 0. 作用域与品牌来源说明

**本规范作用于 `apps/scraper-console`。**
整站方案已确定以该应用承载公开区与授权区。

需注意两处现存偏差：

1. `DESIGN.md` 的 frontmatter 是 `scope: apps/web product surfaces`。
   它的规则写给内部 Web，不是控制台。
   本规范把它的品牌取值与组件契约迁移到控制台。
   迁移范围为颜色、间距、圆角、状态词汇与组件角色，不含页面结构。
2. `DESIGN.md` 规定「产品页不应使用营销级展示字号」。
   公开首页属于营销面，是本条规则的显式例外。
   控制台页面仍守 32px 页面标题。

两套运行时 token 目前不是同一来源：

- Web 导入设计规范 CSS。
- 控制台在 `globals.css` 内联复制。
- 两者相似，但不是单一运行时来源。

因此本规范是目标约定，不是当前已达成状态。

## 1. 规范目标

借鉴 Monid 首页的简约节奏和 Designeer 的紧凑目录。
保留 Data Intelligence Hub 的品牌调性。
不复制参考站的蓝色、标志、纹理与外部字体。

## 2. 品牌映射

参考站做法可以借鉴，具体取值必须换成 DIH 品牌。

| 层次 | 参考站 | DIH 取值 |
|---|---|---|
| 页面底色 | 白色 | 暖纸底 `#f7f2ed` |
| 主要面板 | 白色 | 白色 `--surface-primary` |
| 主要行动色 | `#0016d7` 蓝 | 玫瑰色 `#9b4355` |
| 边框 | 浅灰 | 暖灰 `#ded3cc` |
| 主标题色 | `rgb(30,30,30)` | `--text-primary` |
| 次要文字 | `rgb(107,107,107)` | `--text-secondary` |
| 展示字体 | Outfit | 系统 sans 中文字体栈 |
| 代码字体 | JetBrains Mono | 现有 mono（仅 ID、哈希、载荷） |

允许借鉴的手法：

- 大字号标题加负字距。
- 深浅区块交错形成节奏。
- 满色区块作节奏断点。
- 低对比度背景纹理。

改用 DIH 的表现方式：暖纸底、玫瑰行动色、克制的边界线。

## 3. 排版尺度

沿用产品规范的分级，不逐值照搬参考站的 90px 展示字号。
页脚巨型字标是自有等效物，见 §10。

| 层级 | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| 首页主标题 | 56 / 62 | 600 | 唯一首屏主张 |
| 首页区块标题 | 40 / 46 | 600 | 公开首页区块 |
| 控制台页面标题 | 32 / 38 | 600 | 控制台页面 |
| 面板标题 | 18 / 24 | 600 | 卡片与抽屉 |
| 正文 | 14 / 22 | 400 | 默认界面文字 |
| 标签 | 13 / 18 | 500 | 字段与状态 |
| 元数据 | 12 / 17 | 400 | 时间、来源、ID |

规则：

- 首页可用营销字号，控制台不用。
- 中文标题不使用全大写。
- 标题字距最大不超过 -1px。
- 强调靠层级和留白，不靠反复加粗。
- 目录行不使用展示字号。

## 4. 间距与形状

- 基准单位 4px。
- 间距尺度：4、8、12、16、24、32、48、64、96、120。
- 公开首页区块垂直内边距：96 至 120px。
- 控制台区块垂直内边距：32 至 64px。
- 内容最大宽度 1280px。
- 侧栏宽度 272px。
- 圆角沿用既有语义：4、8、12、16px。
- 胶囊形只用于状态、筛选与分段选择。

留白取舍说明：

参考站首页靠 100 至 140px 内边距形成从容感，总高约 5911px。
本规范保留这种节奏，但把首页总高收在 4500 至 5500px。
理由是内容量少于参考站，不需要那么长的滚动距离。
若实施后觉得过于紧凑，优先加大区块内边距，不动字号。

层次规则：

- 一级：暖纸底，无阴影。
- 二级：白色面板加 1px 边框。
- 三级：抽屉与弹窗加遮罩阴影。
- 不使用卡片套卡片。
- 目录默认用行，不用同尺寸大卡片网格。

## 5. 首页结构

首页是 11 个版块：9 个内容版块，加顶栏与页脚两个骨架。
参考站的供应商版块本期删除，因为没有真实内容。
总高度控制在 4500 至 5500px。

### 5.1 区块顺序

1. **顶栏**
   - 左：品牌名与首字母方块。
   - 中：导航「工具 / 文档 / 接入」，链到 `/tools`、`/docs`、`/connect`。
   - 右：一个中性按钮，进入控制台。
   - sticky，高 72px。

2. **首屏**
   - eyebrow 药丸一个。
   - 主标题两行，一个词用玫瑰色强调。
   - 一行说明。
   - Agent 兼容行，只用文字，不用徽标位图。
   - 一个主行动：可复制的命令条。
   - 收尾句一句。
   - 内容底部对齐，`min-height: calc(50vh + 130px)`。

3. **连接区**
   - 几何线框图解：采集器 → DIH 中枢 → 平台目录。
   - 图解下方接目录墙：catalog 前 24 条。
   - 末尾加一格 CTA，链到 `/tools`。

4. **三步流程**
   - 找能力 → 发采集 → 取产物。
   - 三步等宽，中间用细线连接。
   - 每步一句话，不超过 20 字。

5. **口号与统计**
   - 一句口号。
   - 四个真实计数：286 能力视图 / 258 唯一端点 / 285 已实测 / 248 实测成功。
   - 计数注明来源与日期。

6. **终端演示**
   - 深色卡，等宽字体。
   - 真实运行日志脱敏回放。
   - 右侧列显示记录数与耗时。
   - 不写余额与计费。

7. **接入方式**
   - REST、MCP、Skill 三张等宽卡片。
   - 每张一个标题、一句说明、一个箭头。
   - 点击进入 `/connect`。

8. **行动区**
   - 满色玫瑰背景。
   - 一句主张加一个复制命令。
   - 只保留一个行动。

9. **常见问题**
   - 5 条折叠问答。
   - 答案写 DIH 的真实情况。

10. **供应商区**
    - 参考站有此区。
    - 本期没有真实内容，删除。

11. **页脚**
    - 深色，三列链接。
    - 底部巨型裁切字标，用自有名称。

### 5.2 首屏规则

- 主标题不超过两行。
- 强调词最多一处，用玫瑰色。
- 命令框是唯一主行动，配复制按钮。
- 背景纹理对比度极低，不干扰正文。
- 不使用轮播和自动播放动画。

### 5.3 节奏规则

- 相邻区块底色必须变化一次。
- 满色区块全站最多两处。
- 数字区块紧跟文字区块，避免连续长文。
- 深色区块只用于强调，不连续使用。

## 6. 工具目录

借鉴 Designeer 的紧凑行与明确筛选。

### 6.1 布局

- 桌面：左侧分类栏加右侧结果区。
- 每行：图标、业务名称、一句说明、状态、右侧动作。
- 默认列表视图。
- 网格仅用于媒体产物。
- 窄屏切换为摘要行，不压缩所有列。

### 6.2 筛选与搜索

- 搜索框固定在结果区顶部。
- 分类显示名称与数量。
- 选中态用底色与文字色区分，不只靠颜色。
- 筛选条件写入 URL，返回时保留。
- 空结果显示明确说明，区分无结果、无权限与加载失败。

### 6.3 状态展示

状态词汇沿用产品规范：
草稿、就绪、运行中、已完成、降级、挂起、已取消、失败、有效空结果。

状态不只用颜色表示。
每个状态配图标、文字和一句说明。
「已验证」必须来自真实测试证据，不能来自静态声明。

## 7. 组件角色

只使用这些角色，不新建平行组件库。

| 角色 | 用途 |
|---|---|
| AppShell | 公开区与授权区共享品牌与页头 |
| ToolRow | 目录中的一行能力 |
| ToolDetails | 业务说明与高级参数分层 |
| ParameterForm | 由已验证 schema 驱动 |
| ActionReview | 项目、输入摘要、成本上限与确认 |
| RunStatus | 状态、原因、下一步与时间 |
| ArtifactPreview | 文本、表格与媒体的类型化展示 |
| EvidenceDrawer | 证据来源、时间与限制 |
| StateBlock | 空、加载、错误、无权限四态 |

## 8. 文案规则

- 一句一个意思，短句为主。
- 按钮说明动作和目标，不重复页面标题。
- 错误说明发生了什么、影响什么、如何恢复。
- 危险操作写明对象、后果与是否可撤销。
- 不出现未经核验的数字、价格或供应商名。
- 供应商价格标明为估算，不写成平台售价。
- 中英文之间按语义留白。
- 术语与 [写作标准](../standards/writing-standard-ste.md) 一致。
- 界面用「抽屉」指右侧滑出面板，与写作标准一致。
- 模态框写作「对话框」，不写作「弹窗」。
- 「数据集」不写作「数据资产」。

## 9. 可访问性与动效

- 每个交互元素有可访问名称。
- 键盘可达，焦点环可见。
- 弹窗有明确关闭按钮，支持 Escape，焦点返回触发元素。
- 动画支持 reduced-motion。
- 页面切换不依赖动画揭示内容。
- 目录行的高度不因加载状态跳动。

## 10. 素材红线与等效实现

参考站的配图、标志、图标、字体文件与页面截图是它的资产。
本项目不复制这些文件。

等效原则：

- 采用自有等效物实现同等观感。
- 版面结构、栏目节奏、几何线框手法与动效技术可以借鉴，它们是通用手法。
- 禁止复制参考站的具体素材与素材文件。

禁止清单：

- 不复制参考站的 12 角星 glyph 路径、像素吉祥物造型与二进制纹理的具体画面。
- 不引用参考站 `/logos` 下的第三方徽标位图。
- 不逐字复制参考站的 FAQ、口号与数字。
- 不打包 Outfit、Inter、JetBrains Mono 等外部字体文件。界面用系统字栈，代码字体用现有 `--font-mono`。
- 不采用参考站的蓝色与标志配色。
- 不使用广告轮播与浮动广告。
- 不在首屏展示尚未可用的功能按钮。

数字合规：

- 所有计数只用本项目真实值，并注明来源。
- Agent 兼容行只用文字，不用徽标位图。

## 11. 验收

- 首页总高度在 4500 至 5500px。
- 首屏只有一个主要动作。
- 目录默认列表，检索与筛选保留 URL 状态。
- 新写组件只引用语义 token。
- 桌面、移动、键盘三种路径均可完成主要流程。
- 公开区与控制台无硬编码旧品牌珊瑚色残留。

范围说明：

- 珊瑚色 `#C96F5C` 现存于 `apps/web`，控制台没有。
- 内部 Web 不在本次实施范围，列为后续或不在范围。
- 因此该项只对公开区与控制台生效。

## 12. token 现状与清理债

控制台 `apps/scraper-console/src/app/globals.css` 有约 98 个自定义属性。
目前并存两套词族：

| 词族 | 示例 | 组件引用次数 |
|---|---|---:|
| 语义词族 | `--surface-*`、`--text-*`、`--action-*`、`--border-*` | 约 757 |
| 旧词族 | `--fg-1`、`--bg-1`、`--accent-1` | 约 26 |

旧词族仍是底层取值。例如 `--surface-canvas` 实际引用 `--bg-1`。

因此：

- 「全站颜色只来自语义 token」是新写代码的要求，不是现状描述。
- 旧词族保留为别名层，不直接删除，避免一次性大改。
- 新组件只写语义词族，旧组件在改动时顺手收敛。
- 双词族清理列为后续技术债，不阻塞首期。
