## 6. 术语

| 术语 | 含义 |
|---|---|
| 能力视图 | 工具在某个平台分类下的展示条目 |
| 端点 | endpoint，一个可调用的采集入口 |
| verified | 所需配置存在、无策略拦截、最近一次 test 成功且返回至少 1 条记录 |
| config-gated | 端点存在，但缺凭据或被外访策略拦截 |
| 证据时效 | `evidence_freshness`，标记 verified 证据是否在 14 天内 |
| MCP | Model Context Protocol，共享工具入口 |
| head pin | 迁移 head 的固定值。新迁移必须同步 16 个文件 |
| ABI | 外部数据中心，Apify 原始数据的独立 Postgres 库 |
| VOC | Voice of Customer，用户声音洞察 |
| 禁写结论 | 报告渲染前的机器检查。命中即构建失败 |
| 三棒模型 | PMO 能力进度算法：cap = 0.3×P1 + 0.4×P2 + 0.3×P3 |
| 冻结快照 | 保留但不再更新的环境。B 属此类 |
